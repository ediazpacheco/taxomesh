# Security policy

## Supported versions

`taxomesh` is pre-1.0. A security fix goes into the next release only; earlier releases are not
patched.

## Reporting a vulnerability

Report a vulnerability by email to the maintainer, at ediazpacheco@gmail.com, and not in a public
issue. Say what is affected, how to reproduce it, and which version you ran.

`taxomesh` is a personal project, so there is no guaranteed response time, as for any issue.
