# Quickstart: Django CLI Compatibility and Admin Graph View

**Feature**: `015-django-cli-admin`
**Date**: 2026-03-01

---

## Using the CLI with a Django backend

### 1. Configure `taxomesh.toml`

```toml
[repository]
type = "django"
using = "default"   # optional — "default" is the default alias
```

### 2. Set `DJANGO_SETTINGS_MODULE`

The taxomesh CLI must be run in an environment where Django is configured:

```bash
export DJANGO_SETTINGS_MODULE=myproject.settings
taxomesh category list
```

Without `DJANGO_SETTINGS_MODULE`, the CLI exits with:

```
Error: Django settings are not configured. Set the DJANGO_SETTINGS_MODULE environment
variable before running taxomesh with type = 'django'.
```

### 3. Inspect effective configuration

```bash
export DJANGO_SETTINGS_MODULE=myproject.settings   # not required for --show-config
taxomesh --show-config
```

Output:

```toml
# taxomesh effective configuration
# Generated by: taxomesh --show-config

[repository]

# Controls the storage backend type.
# Accepted values: "yaml", "json", "django"
# Default: "yaml"
type = "django"

# Django database alias (key in Django DATABASES settings).
# Default: "default"
using = "default"
```

`--show-config` does **not** require `DJANGO_SETTINGS_MODULE` — it only reads `taxomesh.toml`.

## Using the Django admin graph view

### Prerequisites

- `taxomesh.contrib.django` in `INSTALLED_APPS`
- `APP_DIRS=True` in `TEMPLATES` (Django default — required for template discovery)
- Django admin enabled (`django.contrib.admin` in `INSTALLED_APPS`, admin URLs configured)

### Accessing the graph

1. Log in to Django admin (`/admin/`)
2. Navigate to the **Taxomesh** section
3. Click **Graph** (shown alongside Category, Item, Tag links)

The graph page is at `/admin/taxomesh_contrib_django/categorymodel/graph/`.

### What you see

- **Categories** are shown in a tree, indented by hierarchy depth
- Each category row shows: name, UUID, enabled status (✓/✗), and external ID (if set)
- **Items** appear under their category, showing: external ID, item UUID, and enabled status
- Categories with multiple parents appear under each parent (DAG — not deduplicated)
- An empty taxonomy shows: "No categories found. Add one to get started."
- If the database is unreachable, an error message is shown on the page

### No JavaScript required

The graph page is a static server-rendered HTML tree. No browser-side JavaScript or external
libraries are needed.
