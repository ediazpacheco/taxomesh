# Implementation Plan: HTTP Search Support for contrib.api

**Branch**: `037-contrib-api-search` | **Date**: 2026-03-15 | **Spec**: [spec.md](spec.md)

## Summary

Add `SearchItemsRequest` / `SearchCategoriesRequest` schemas, `search_items` / `search_categories` handlers, and `items_to_list` / `categories_to_list` serializers to `taxomesh.contrib.api`. All business logic is already implemented in `TaxomeshService`; this feature is purely a thin delegation + serialization layer. One new domain constant (`MAX_SEARCH_QUERY_LENGTH`) is required by Principle IV.

## Implementation Steps

### Step 1 — Add `MAX_SEARCH_QUERY_LENGTH` constant

**File**: `taxomesh/domain/constants.py`

Add:
```python
MAX_SEARCH_QUERY_LENGTH: Final[int] = 500
```

Place it with other `MAX_*` constants (near `MAX_DESCRIPTION_LENGTH`).

---

### Step 2 — Add `SearchItemsRequest` and `SearchCategoriesRequest` schemas

**File**: `taxomesh/contrib/api/schemas.py`

Import additions:
```python
from uuid import UUID
from taxomesh.application.search import DEFAULT_SEARCH_LIMIT
from taxomesh.domain.constants import MAX_SEARCH_QUERY_LENGTH
```

Add two `BaseModel` subclasses using `Annotated[str, Field(max_length=MAX_SEARCH_QUERY_LENGTH)]` for `q`, and `DEFAULT_SEARCH_LIMIT` as the default for `limit`. Full signatures in `contracts/search-api.md`.

---

### Step 3 — Add `search_items` and `search_categories` handlers

**File**: `taxomesh/contrib/api/handlers.py`

Import additions:
```python
from taxomesh.contrib.api.schemas import SearchItemsRequest, SearchCategoriesRequest
```

Both handlers: accept `(service: TaxomeshService, params: SearchItemsRequest | SearchCategoriesRequest)` → unpack all fields as kwargs to the corresponding service method → return the result unchanged. No exception handling.

---

### Step 4 — Add `items_to_list` and `categories_to_list` serializers

**File**: `taxomesh/contrib/api/serializers.py`

Import additions:
```python
from taxomesh.domain.models import Category, Item
```

Both functions: one-liner — `return [obj.model_dump(mode="json") for obj in collection]`.

---

### Step 5 — Tests (written before implementation — TDD)

**Files**: extend existing `tests/contrib/test_api_*.py`

#### `test_api_schemas.py` additions
- `SearchItemsRequest` instantiates with required `q` only (all defaults applied)
- `SearchItemsRequest` rejects `q` over 500 chars
- `SearchCategoriesRequest` same two cases
- `category_id` and `parent_id` accept `None` and valid `UUID`

#### `test_api_handlers.py` additions
- `search_items` with a matching query returns expected items from an in-memory service
- `search_items` with `enabled_only=True` excludes disabled items
- `search_items` with blank `q` returns `[]`
- `search_items` propagates `TaxomeshCategoryNotFoundError` for unknown `category_id`
- `search_categories` with a matching query returns expected categories
- `search_categories` with blank `q` returns `[]`

#### `test_api_serializers.py` additions
- `items_to_list([item])` returns a list of one dict with string UUID keys
- `items_to_list([])` returns `[]`
- `categories_to_list([category])` returns a list of one dict with string UUID keys
- `categories_to_list([])` returns `[]`
