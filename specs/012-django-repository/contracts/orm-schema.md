## Cross-Database Compatibility Notes

| Feature | SQLite | PostgreSQL | MySQL |
|---------|--------|-----------|-------|
| `UUIDField` | Stored as CHAR(32) | Stored as UUID native | Stored as CHAR(32) |
| `JSONField` | Stored as TEXT (JSON1 ext required, available SQLite ≥ 3.38) | Stored as JSONB | Stored as JSON |
| `BooleanField` | Stored as INTEGER (0/1) | Stored as BOOLEAN | Stored as TINYINT(1) |
| `unique_together` | Unique index | Unique index | Unique index |
| `AUTO INCREMENT` PK | INTEGER | BIGSERIAL | BIGINT AUTO_INCREMENT |

Django 4.2 handles all these differences transparently. No database-specific migration
operations are needed for the initial migration.

- Future model changes MUST produce new numbered migrations (e.g., `0002_...`), never modify
