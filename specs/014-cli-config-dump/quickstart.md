# Quickstart: --show-config Flag

**Branch**: `014-cli-config-dump` | **Date**: 2026-02-28

## What This Feature Does

`taxomesh --show-config` prints the current effective configuration in TOML
format — with every setting annotated by a comment — and exits. It shows
defaults for any setting not present in the active config file.

## Bootstrap a Config File

```sh
# No taxomesh.toml yet? Generate one with all defaults:
taxomesh --show-config > taxomesh.toml

# Then edit it to override only what you need.
```

## Inspect the Effective Config

```sh
# With auto-discovered taxomesh.toml in the current directory:
taxomesh --show-config

# With an explicit config file:
taxomesh --config path/to/taxomesh.toml --show-config
```

## Example Output

```toml
# taxomesh effective configuration
# Generated by: taxomesh --show-config
# All settings are shown with their active values (defaults applied for any unset key).
# Pipe this output to taxomesh.toml to save your current configuration:
#   taxomesh --show-config > taxomesh.toml

[repository]

# type: the storage backend format taxomesh uses to persist your taxonomy.
#   Accepted values : "yaml" (default), "json"
#   Default         : "yaml"
type = "yaml"

# path: path to the storage file where taxomesh reads and writes your taxonomy.
#       Relative paths are resolved from the directory where you run the CLI.
#   Default (yaml): "data/taxomesh.yaml"
#   Default (json): "data/taxomesh.json"
path = "data/taxomesh.yaml"
```

## Key Behaviours

- **Always shows all settings**: even if your `taxomesh.toml` only overrides one key,
  all settings appear in the output with their active (merged) values.
- **Pipe-safe**: TOML output goes to stdout; error messages go to stderr.
- **Terminal flag**: when `--show-config` is present, no other command runs.
- **Works with `--config PATH`**: `taxomesh --config staging.toml --show-config`
  shows the effective config for `staging.toml`.

## Finding All Supported Settings

```python
from taxomesh.adapters.cli.config import CONFIG_KEYS

print(CONFIG_KEYS)
# ["repository.type", "repository.path"]
```
