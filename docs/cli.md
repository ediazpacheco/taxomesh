# CLI Reference

The `taxomesh` command reads and changes a taxonomy without Python code: to explore it, to run a
smoke test, to give a demonstration or to correct stored data by hand.

Install the `cli` extra, which brings typer and rich, and the `taxomesh` command is available:

```bash
pip install "taxomesh[cli]"
```

Without the extra, `taxomesh` exits with status 1 and a message naming it.

The command builds its service as `TaxomeshService()` does: from the `taxomesh.toml` in the
working directory, or the one `--config` names, and otherwise from a YAML file under `data/` (see
[Configuration](configuration.md)).

Each command is the name of the Python member it calls, with `_` written `-`, under its entity's
group: `taxomesh item place-in` calls `svc.items.place_in`. A command calls one member, and an
option it takes is an argument of that member, two of them spelled their own way: `--state` is
`enabled`, and `--relation-type`, repeated, is `relation_types`. An option that names an entity
ends in `-id`, as HTTP spells it: `--parent-id`, `--category-id`, `--item-id`, `--tag-id`. Every
command takes `--help`.

The lookups by key (`get`, `get_by_slug`, `get_by_external_id` and the `get_many` forms),
`search`, `move` and `reorder` have no command, and no `create` or `update` command takes
metadata: write it from Python or over HTTP.

## A short session

The command prints each identifier that it creates. The `<…-id>` placeholders stand for them.

```console
$ taxomesh category create --name Music
Music (id: <music-id>)
$ taxomesh item create --name "Kind of Blue" --external-id kind-of-blue
Kind of Blue (id: <item-id>, external_id: kind-of-blue)
$ taxomesh item create --name Milestones
Milestones (id: <other-item-id>)
$ taxomesh item place-in <item-id> --category-id <music-id>
Placed item <item-id> in category <music-id> at sort index 0
$ taxomesh tag create --name live
live (id: <tag-id>)
$ taxomesh item tag <item-id> --tag-id <tag-id>
Added tag <tag-id> to item <item-id>
$ taxomesh item relate <item-id> <other-item-id> same-artist
Stored relation: <item-id> --[same-artist]--> <other-item-id>
$ taxomesh category roots
--- Categories ---
Music (id: <music-id>)
--- Total: 1 ---
```

`update` changes only what it is given: `--enable` or `--disable` sets the state, and an omitted
option keeps the stored value.

`category delete`, `item delete` and `tag delete` also delete every link that names the entity, on
every backend: a category's parent and child links and its placements, an item's placements, tags
and relations, and a tag's links to items.

## `graph`

```text
Taxonomy
└── Music (id: 11111111-1111-1111-1111-111111111111)  ✓
    └── Jazz (id: 22222222-2222-2222-2222-222222222222)  ✓
        └── Kind of Blue (id: 33333333-3333-3333-3333-333333333333, external_id: kind-of-blue)  ✓
```

`graph` draws three levels in full by default, and the categories one level below them without
their items or children; `--max-depth 0` removes the limit. The tree is drawn down from the
top-level categories, one branch per path, and the drawing ends on any stored shape, at every
depth:

- A category shared by several parents is drawn under each of them, so nested shared branches
  multiply the rows. Past `MAX_EMITTED_NODES` (100,000) categories drawn, `graph` stops with exit
  status 1 and asks for a smaller `--max-depth`.
- A category already on the path being drawn, which only a cycle in stored data produces, is
  drawn with its items and marked `↻ cycle`, and is not descended into.
- A category that no top-level category reaches is not drawn: one holding no parent link at all,
  which only a write to the repository, not through the service, can leave, the members of a
  stored cycle that no top-level category reaches, and any category reached only through those.
  When every stored category is such a one, `graph` prints *No categories found*.

Each drawn item's outgoing relations are drawn below it, read in one batch for every item drawn;
`--no-show-relations` leaves them out. A relation is drawn when its related item passes `--state`
too.

`svc.graph().walk()` in the [Python API](python-api.md#the-graph) enumerates every category exactly
once, whatever the shape.
